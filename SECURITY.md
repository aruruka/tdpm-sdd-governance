# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of `tdpm-sdd-governance` seriously. If you discover a security vulnerability, please report it responsibly.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report security issues by sending an email to:
keraymondyan69@gmail.com

Please include:
- A description of the issue and potential impact
- Steps to reproduce or proof-of-concept
- Any possible mitigations you have identified

### Response Timeline

- **Initial Response**: We will acknowledge receipt of your report within 48 hours.
- **Assessment**: We will confirm the vulnerability and determine the severity within 5 business days.
- **Fix & Disclosure**: We will prepare a patch, coordinate disclosure with you, and release a security advisory.
